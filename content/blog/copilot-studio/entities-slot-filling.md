# Entities
1. An entity is a unit of information that represents a certain type of real-world subject.
2. Example: phone number, postal code, person's name
3. An agent can recognize relevant information from a user input and save it for later use.
4. The identified information is saved in a variable of the appropriate type.

## Prebuilt Entities
1. To use 'Money' entity as an example: Open an agent -> Settings -> Entities -> Select Money
