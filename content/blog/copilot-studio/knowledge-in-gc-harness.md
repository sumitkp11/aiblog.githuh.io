## Knowledge Source
- It is configured from the Build tab.
- Knowledge sources are the data the agent can access when responding to user queries. It can refer to specific documents, websites, organization data and structured databases.
- If knowledge isn't provided, it relies only on its general training and instructions.

## Reasons to add Knowledge Sources
- To ground responses in specific information
- to keep answers relevant to the organization's latest content
- to scope the agent to answer only from approved sources
- to reference only from the internal documents, policies and procedures.


## Knowledge Sources Types
- Featured sources: Public websites, SharePoint, OneDrive for Business, Salesforce, ServiceNow, Azure SQL.
- Advanced sources: Azure DevOps Wiki, Azure DevOps Work Items, Custom Connector, Enterprise websites
- Supported file uploads: PDF, Word, Excel and PowerPoint.
- Connector-based enabled if the required connectors are installed and consent has been given to.


## Managing Knowledge Sources
- After adding knowledge sources, we can view, update and remove them from the Knowledge tab.
- We can also turn web search on or off.
