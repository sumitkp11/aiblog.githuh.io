# Explore Microsoft Copilot Studio and agent harnesses

## Learning Path-1: Get started with Ai-first solutions

- Microsoft redesigned Power Platform around an AI-first philosophy.
- Power Platform consists of 6 components: Power Apps, Power Automate, Power Pages, Microsoft Copilot Studio, AI Builder and Power BI.

## Understand Component Purpose
1. PowerApps:
   - Build custom user interfaces
   - Control over screen layout and mobile-friendly experiences
  
2. Power Automate
   - Handles process automation and integration.
   - Cloud flows orchestrate logic across connectors and services.
   - Built-in approval actions create structured human-in-the-loop experience.
  
3. Microsoft Copilot Studio
   - to build conversational and autonomous agents.
   - autonomous agents respond to triggers such as a new record, scheduled time, incoming email.
   - process requires natural language interaction or without constant human input.

5. AI Builder
   - Provides pretrained AI models and a prompt-building environment.
  
6. Power Pages
   - External facing web experience.
   - Provides configurable web portal with secure authentication.
