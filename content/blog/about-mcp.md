## Model Context Protocol or MCP
- MCP is an open-source standard for connecting AI applications to external systems.
- It enables them to access key information and perform tasks.
- In Copilot Studio, it allows makers to integrate existing knowledge servers and APIs directly.

## What can MCP do?
- Agents can access Google calendar becoming a more personalized AI assistant.
- Claude Code can generate an entire web app using Figma design.
- Enterprise chatbots can connect to multiple databases across an organization.
